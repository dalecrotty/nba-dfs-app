# DFS Cruncher (private app)

The page for Dale's DraftStars lineup app, served by GitHub Pages at
https://dalecrotty.github.io/nba-dfs-app/. It shows nothing without a
sign-in (Supabase Auth, email allowlist); every number comes from the
`dfs` Edge Function in the NBA Supabase project. Source of truth:
`app/page.html` in dalecrotty/nba-dfs-personal; copy it here as
`index.html` to publish.
